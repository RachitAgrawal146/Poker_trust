# BUNDLE_MANIFEST.md — what's in the arXiv source bundle, and why

**Tarball:** `arxiv_submission.tar.gz` · **Engine:** pdflatex · **Bib:** frozen `main.bbl`

## Source provenance (important)

The repository contains two divergent versions of `paper_resources/manuscript/main.tex`:

- **`origin/claude/focused-thompson-1gTAE`** — has the borrowed Figure 1
  (`00_game_of_trust.png`, Nicky Case "Evolution of Trust") and `\label{fig:pd}`.
  This is the version the task targets (Step D) and the one the author
  previously identified as canonical. **← used as the source.**
- The current working branch's `main.tex` — a divergent edit whose lead figure
  is `01b_five_tier_ladder_with_unbounded.png` and which has **no** Figure 1.
  Using it would make Step D a no-op. **← not used.**

Files were extracted read-only from the focused-thompson branch via `git show`;
the originals were never edited in place. All work was done under `arxiv_build/`.

## Removed content (the only permitted content change — Step D)

| Item | Action | Reason |
|---|---|---|
| `00_game_of_trust.png` | excluded from bundle | borrowed third-party image (Nicky Case, *Evolution of Trust*) — author holds no rights; arXiv disallows |
| `\begin{figure}…\end{figure}` float for it (orig. lines 406–417) incl. `\caption{…}` and `\label{fig:pd}` | deleted from `main.tex` | removes the float for the borrowed image |

Surrounding prose was **not** touched. The body still contains
`Figure~\ref{fig:pd}` (main.tex:420), which now resolves to "??". This is left
for the author and recorded in `TODO.md`. Remaining figures auto-renumbered
2–7 → **1–6** on recompile (verified in `.aux`).

## Path/filename fixes (mechanical only — no content change)

| Location | Before | After | Why |
|---|---|---|---|
| `main.tex:64` | `\graphicspath{{../figures/}{./figures/}{./}}` | `\graphicspath{{figures/}{./}}` | `../figures/` points outside the bundle; figures now ship in `figures/` |
| `main.tex:907` | `\input{../tables/per_archetype_p31.tex}` | `\input{tables/per_archetype_p31.tex}` | `\input` ignores `graphicspath`; `../` would escape the bundle |
| `main.tex:1143` | `\input{../tables/behavioral_shift_p1_p31.tex}` | `\input{tables/behavioral_shift_p1_p31.tex}` | same |
| `main.tex:1223` | `\input{../tables/tma_by_archetype.tex}` | `\input{tables/tma_by_archetype.tex}` | same |

No files were renamed: all source names are already lowercase ASCII, no spaces,
no case collisions.

## Excluded files (and why)

| File / class | Reason for exclusion |
|---|---|
| `references.bib` | superseded by the frozen `main.bbl`; omitting it guarantees arXiv uses the frozen bibliography and never re-runs BibTeX |
| `00_game_of_trust.png` | borrowed Figure 1 (see Step D above) |
| `paper_resources/figures/` unused images — `01_four_tier_ladder`, `01b_five_tier_ladder_with_unbounded`, `02_per_seed_ladder`, `04_behavioral_shift`, `07_phase2_bounded_vs_unbounded` (non-aggressive), `08_*`, `09_*`, `10_param_drift_unbounded` (non-aggressive), `11_*`, `12_*`, `13_*`, and `archetypes/*` (8 portraits) | not referenced by `\includegraphics` in this `main.tex` (the `\archentry` macro is text-only); arXiv should ship only referenced assets |
| `paper_resources/tables/headline_ladder.tex`, `economic_inversion.tex` | not `\input` by this `main.tex` |
| compiled PDF, `.aux .log .out .blg .toc .lof .lot .fls .fdb_latexmk .synctex.gz` | build artifacts — arXiv regenerates them |
| `.git/`, repo files, editor backups, `.DS_Store` | not part of the manuscript |
