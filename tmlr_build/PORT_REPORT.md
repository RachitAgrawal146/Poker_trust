# PORT_REPORT.md — arXiv two-column source → TMLR anonymized submission

**Input:** the verified arXiv bundle (`arxiv_build/bundle/` — the source of the
clean 12-page `paper.pdf`), untouched.
**Output:** `tmlr_submission/` + `tmlr_anonymous.pdf` (19 pages).
**Style files:** official `tmlr.sty` / `tmlr.bst` fetched from
`github.com/JmlrOrg/tmlr-style-file` (raw.githubusercontent, `main` branch) —
not hand-written, not modified. The template example (`main.tex` of that repo)
was used as the layout convention reference.

## 1 · Preamble swap (template mechanics)

New preamble: `\documentclass[10pt]{article}` + `\usepackage{tmlr}` — the plain
package, i.e. **anonymous submission mode** (no `[accepted]`/`[preprint]`).

| Removed (why) | Kept verbatim (from the old preamble) |
|---|---|
| `geometry` (TMLR sets its own 6.5in×9in text block) | `xcolor` + all archetype/science color definitions + `\arch` |
| `mathptmx`, `helvet`, `[T1]fontenc` (tmlr.sty loads T1 + `lmodern`) | `caption`/`subcaption` + `\captionsetup` |
| `titlesec` block (tmlr.sty defines sectioning) | `booktabs`, `array`, `tabularx`, `multirow` |
| `fancyhdr`+`lastpage` config incl. the custom footer **"Agrawal (year) — page N of M"** and `firstpage` style (tmlr.sty installs its own running header) | `tcolorbox[most]` + the `storyhand` box style |
| `\usepackage[numbers,round]{natbib}` (option clash — tmlr.sty `\RequirePackage{natbib}` + `\setcitestyle{authoryear,round,…}`) | `xurl` + `hyperref` colorlinks config |
| `\citenumfont`/`\bibnumfmt` renewcommands (numeric-mode-only natbib commands; error under authoryear) | `\rtp`, `\bbar`, `\archentry` macros + hyphenation params (`\emergencystretch` etc.) |
| `tikz` (unused — its comment referenced the removed Figure 1, which was a PNG anyway) | `microtype`, `inputenc`, `amsmath`, `amssymb` |
| `\researchbadge`, `\category` macros (custom title block only) | `\graphicspath{{figures/}{./}}` (re-added — see §3) |
| header comment line naming the author | `\bibliographystyle{plainnat}` (frozen-`.bbl` provenance) |

**Title:** passed to `\title{}` **character-identical** to the source.
**Abstract:** the paragraph text was copied **byte-identical** from the source
(only the surrounding `\colorbox`/`minipage`/font-size styling wrapper was
dropped; the TMLR `abstract` environment supplies the styling).
**Author field:** `\author{Anonymous authors\\Paper under double-blind review}`
per the template's anonymous-mode convention — tmlr.sty prints exactly that
regardless of the field when the plain package is used.

## 2 · Bibliography adjustment (template-forced, mechanical)

- tmlr.sty hard-loads natbib and sets `authoryear, round`. The old explicit
  `\usepackage[numbers,round]{natbib}` had to go (option clash), so in-text
  citations change appearance from **numeric "(1)" to author–year
  "(Axelrod, 1984)"**. No citation command in the body was edited
  (12 `\citep`, 1 `\cite` — all natbib-compatible).
- The **frozen `main.bbl` is kept** (generated by BibTeX/plainnat). plainnat
  writes `\bibitem[Author(year)]{key}` labels, which are fully compatible with
  natbib's author–year mode, so all 17 citations resolve with **zero undefined
  references and no BibTeX run**. `references.bib` and `tmlr.bst` are also
  shipped so the bibliography can be regenerated; `\bibliographystyle{plainnat}`
  is retained to match the frozen `.bbl`'s provenance.
- The manual `\subsection*{References}` + `\footnotesize` before
  `\bibliography` were dropped: `thebibliography` prints its own References
  heading under the TMLR layout (the manual heading would have doubled it;
  the `\footnotesize` was a two-column space hack).

| Content order | unchanged — body is the source from `\section{Introduction}` onward, byte-identical except the logged tail edits | — |
